# Mini Task Manager

A simple task manager built for practicing frontend-backend communication and backend deployment.

## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Python
- Flask
- Flask-CORS

## Features

- View tasks
- Add tasks
- Mark tasks as completed
- Delete tasks
- REST API
